El un sistema para llevar el control libros en una billioteca, tiene capacidad de registrar usarios, registrar libros, realizar prestamos, tiene logica  usuarios y préstamos de una biblioteca universitaria.

El proyecto implementa varias de las estructuras de datos segun los temas del curso.
